# 📩 SMS Spam Detection Web App

A Machine Learning + NLP based web application that classifies SMS messages as **Spam 🚫** or **Ham ✅**.

---

## 🚀 Live Demo

👉 https://sms-spam-detector-dd2c6iq2xiicnmegalm4xf.streamlit.app/

## 📂 GitHub Repository

👉 https://github.com/Prathamesh-code-sudo/SMS-spam-detector

---

## 🧠 Features

* Real-time SMS classification
* NLP-based text preprocessing
* TF-IDF feature extraction
* Random Forest classification
* Interactive web interface using Streamlit

---

## 🛠️ Tech Stack

* Python
* Natural Language Processing (NLP)
* Scikit-learn
* Random Forest Algorithm
* Streamlit

---

## ⚙️ How It Works

1. User inputs SMS message
2. Text is cleaned using NLP techniques
3. Converted into numerical features using TF-IDF
4. Model predicts whether message is Spam or Ham

---

## 📊 Model Details

* Algorithm: Random Forest Classifier
* Accuracy: ~97%
* Dataset: SMS Spam Collection Dataset

---

## ▶️ Run Locally

```
pip install -r requirements.txt
streamlit run app.py
```
